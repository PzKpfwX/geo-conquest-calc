# GeoConquest — калькулятор клана

Браузерное приложение без бэкенда и внешних зависимостей. Расчёт пяти клановых навыков, личного опыта и сравнение результатов в журнале.

## Запуск

Нужен Node.js 22 или новее. Установка пакетов не требуется.

```sh
npm run dev
```

Открыть http://127.0.0.1:5173. Если PowerShell блокирует `npm.ps1`, используйте `npm.cmd run dev` или `node scripts/serve.mjs`.

```sh
npm test
npm run build
```

Сборка копирует приложение в `dist/` для размещения в корне любого статического хостинга. Локальный HTTP-сервер нужен только для разработки; приложение не обращается к API.

## Поведение

- Все игроки активны. Один выбранный навык равен уровню минус один; остальные равны нулю.
- Веса применяются отдельно для каждого навыка: 100%, 70%, 45%, 25%, далее 10%. При равенстве уровней сохраняется порядок добавления.
- Считается личный опыт за введённые действия. Захваты — успешные, без повторного применения вероятности PvP.
- Удержание считается за сутки при постоянной площади и делится на всех игроков в списке.
- Линейные бонусы приняты как допущение. Промежуточные результаты не округляются; отображается до двух знаков после запятой.
- Игроки и последние корректные значения полей сохраняются в `localStorage` под ключом `geoconquest-calculator-v1`. Данные привязаны к адресу сайта и браузеру.
- Журнал существует только в памяти страницы, сохраняет снимки навыков и исходных данных. Перезагрузка очищает журнал. Цвет и стрелки сравнивают с предыдущей записью с точностью отображения.
- Удаление игрока можно отменить в течение 10 секунд (последнее удаление). Очистка журнала требует подтверждения.

## Структура

- `src/calculations.js` — чистые функции расчёта, валидация, сравнение чисел.
- `src/storage.js` — сохранение и проверка данных, обработка недоступного хранилища.
- `src/app.js` — интерфейс и состояние; `src/styles.css` — адаптивное оформление.
- `test/calculations.test.js` — формулы, граничные случаи, снимки журнала и хранение.
- `docs/geoconquest_rules.md` — правила игры и допущения модели.
