# GeoConquest — правила для калькулятора

Источник: FAQ и уточнения игрока (ноябрь 2026). Метки: **подтверждено** — непосредственно из FAQ/уточнений; **допущение** — проверить в игре.

## Карта и захват (подтверждено)
- Игровая карта состоит из гексов. Территория — принадлежащие игроку/клану гексы.
- За пределами своей территории движение оставляет временный след; при возвращении на свою территорию замкнутый контур захватывает гексы внутри. В новом месте можно создать колонию и замкнуть след на ней.
- След исчезает после часа без движения; противники могут его оборвать. При скорости >8 м/с след не создаётся. Другие игроки и следы видны в радиусе 5 км (FAQ: ~300 гексов).
- Захват чужих гексов вероятностный; при неудаче они остаются у владельца.
- В клане территория общая; опыт за удержание делится между участниками.

## XP (подтверждено)
- Пройденный гекс: **5 XP**.
- Успешно захваченный нейтральный гекс: **4 XP**.
- Успешно захваченный чужой гекс: **8 XP**.
- Удержание территории: **0.003 × N^0.7 XP каждые 5 минут** на всю территорию из N гексов; **288 начислений в сутки**. В клане делится между участниками.

## Характеристики (подтверждено)
- **Натиск** — повышает шанс захвата чужой территории.
- **Стойкость** — снижает шанс захвата своей территории.
- **Экспансия** — +4% к XP от захвата за очко.
- **Темп** — +5% к XP от передвижения за очко.
- **Доход** — +3% к XP от удержания за очко.
- Начальные значения всех характеристик = **0**, начальные очки = **0**. **Уточнение игрока для приложения:** на уровне 1 доступно 0 очков, бюджет игрока уровня `L` равен `L − 1` очкам (например, уровень 50 → 49 очков). В текущем калькуляторе все очки вкладываются в один обязательный выбранный навык; остальные равны нулю. Ограничений на максимальное значение отдельного навыка нет. Очки можно сбрасывать и перераспределять.

## Клановые характеристики (подтверждено)
Для каждой характеристики отдельно отсортировать **активных** участников по её личному значению по убыванию. Вклад 1-го: 100%, 2-го: 70%, 3-го: 45%, 4-го: 25%, 5-го и последующих: 10%.

`clan_stat = sum(value_i * weight_i for i, value_i in enumerate(sorted(active_values, reverse=True)))`

Активный участник — набравший >0 очков Актива за последние 7 дней. Неактивные не участвуют в расчёте клановых характеристик. **Все пять характеристик используются в клановом виде во всех расчётах** (подтверждено игроком): Темп/Экспансия/Доход действуют для каждого участника, Натиск/Стойкость — в PvP. Клан действует как единое целое. Неактивные не вносят вклад в характеристики; при оптимизации можно считать всех 15 участников активными.

## PvP (подтверждено)
`chance_percent = max(37, min(100, 87 + attacker_assault - defender_resilience))`

Разница в 1 очко меняет шанс на 1 процентный пункт. Нижний предел 37%, верхний — 100%. При подсчёте ожидаемого XP от атак учитывать вероятность успешного захвата, а не начислять 8 XP за каждую попытку.

## Формулы калькулятора (линейность бонусов — допущение)
```python
WEIGHTS = [1.0, 0.70, 0.45, 0.25]
def clan_stat(values):  # values: личные значения только активных участников
    return sum(v * (WEIGHTS[i] if i < 4 else 0.10)
               for i, v in enumerate(sorted(values, reverse=True)))

def daily_xp(walked, neutral_captured, enemy_captured, territory,
             members, tempo, expansion, income):
    move = 5 * walked * (1 + 0.05 * tempo)
    capture = (4 * neutral_captured + 8 * enemy_captured) * (1 + 0.04 * expansion)
    holding = 0.003 * territory**0.7 * 288 / members * (1 + 0.03 * income)
    return {'move': move, 'capture': capture, 'holding': holding,
            'total': move + capture + holding}
```
Входные `neutral_captured`, `enemy_captured` — **успешно** захваченные гексы. `tempo`, `expansion`, `income` — **клановые**, а не личные характеристики. `members` — количество участников клана, между которыми поровну делится пассивный XP (для модели включать всех участников независимо от активности; правила округления неизвестны). Не округлять промежуточные вычисления без подтверждения.

## Уровни
- До 37-го уровня: сообщена формула `100 + 20*n + 6*n**2`, `n` — уровень. **Не уточнено**, относится ли значение к переходу `n -> n+1` и как обрабатывается граница.
- После 37-го: каждые четыре уровня требуют столько же опыта, сколько все предыдущие уровни вместе; описано как приблизительно +19% к цене следующего уровня. **Точная рекурсия/округление неизвестны** — не заменять без проверки на строгое умножение на 1.19.

## Геометрия гекса (параметры модели)
- Для калькулятора использовать **H3 resolution 13**, согласно опытным замерам игрока. Это **приближение**, а не независимо подтверждённая конфигурация игрового сервера.
- Средняя площадь ячейки ≈ **43.87 м²**; средняя длина ребра ≈ **4.09 м**.
- Для приближения правильным шестиугольником: расстояние между центрами соседних ячеек ≈ `sqrt(3) * 4.09 ≈ 7.09 м`, между противоположными вершинами ≈ `8.18 м`, между противоположными сторонами ≈ `7.09 м`.
- Оценка для маршрута, проходящего через центры последовательных соседних гексов: `walked_hexes ≈ distance_m / 7.09`. Это **не точная** конверсия: реальное число посещённых ячеек зависит от траектории, а H3-гексы имеют неодинаковую геометрию. Предпочтителен прямой ввод числа гексов; коэффициент перевода сделать настраиваемым.

## Оставшиеся неопределённости
1. Точная рекурсия стоимости уровней после 37-го и правила округления; значение формулы до 37-го на границе перехода.
2. Правила округления начисляемого XP и PvP-вероятностей.
3. Дополнительные эффекты временных усилений, если включать их в симуляцию.
4. Реальная геометрия маршрута для конвертации километров в число посещённых гексов.

## Требования к оптимизатору
- Каждый игрок уровня `L` имеет `L − 1` целых неотрицательных очков. В текущем приложении все очки распределяются в один выбранный навык; оптимизатор не входит в текущий функционал.
- Для **каждого навыка отдельно** пересортировать игроков по убыванию личного значения, затем применить коэффициенты кланового вклада. Не фиксировать ранги за игроками.
- XP от Темпа и Экспансии рассчитывать отдельно по действиям каждого участника, но с **одинаковыми клановыми бонусами**. Доход от территории делить поровну на всех участников.
- Для сравнения билдов учитывать и клановый XP, и Натиск/Стойкость; без целевых ограничений по PvP единственного оптимального распределения нет.
